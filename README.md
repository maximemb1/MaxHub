# Atelier - base de site React

Une page d'accueil responsive construite avec React et Vite. Le contenu et les
styles sont volontairement simples à adapter à votre projet.

## Demarrer

```bash
npm install
npm run dev
```

Ouvrez l'adresse affichée par Vite dans le terminal. Pour vérifier la version de
production et les regles de code :

```bash
npm run build
npm run lint
```

## Modifier le site

- `src/App.jsx` contient les sections, les textes et les liens.
- `src/App.css` contient les styles de la page et les regles responsive.
- `src/index.css` contient les styles et couleurs globaux.
- `index.html` contient le titre et les metadonnees de la page.

Pensez à remplacer le nom « atelier », l'adresse e-mail d'exemple et les textes
de présentation par les informations de votre projet.
